# МӨР v79

Мэдэгдлийн хуудасны засвар:
- Хэрэглэгч солигдох бүрд жагсаалтын төлөв шинэчлэгдэнэ.
- Өмнөх хүсэлтийн хариу шинэ жагсаалтыг дарахгүй.
- Хуудаснаас гарсны дараах pending үйлдэл navigation хийхгүй.
- Уншсан болгох үйлдлүүд давхар ажиллахгүй; серверийн төлөвийг дахин авна.
- Үйлдлийн алдааг toast-аар харуулж жагсаалтыг хадгална.

Шалгалт: TypeScript, ESLint амжилттай, 122/122 тест.
Production build болон live/mobile харагдацыг энэ удаа баталгаажуулаагүй.
Өмнөх build оролдлогыг автомат approval review Sentry рүү source map/telemetry илгээж болзошгүй гэж хориглосон тул давтан оролдоогүй.
Өмнөх шинэчлэлүүд багтсан. Нэмэлт SQL шаардлагагүй. .env.local файлаа хадгална.

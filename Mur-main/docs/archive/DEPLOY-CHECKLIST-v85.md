# МӨР v85 — Live audit нэмэлт засвар

Энэ нь бүрэн төсөл биш. Одоо ашиглаж буй төсөл дээр задлах нэмэлт багц.

## Хийгдсэн
1. Onboarding зөвхөн нүүрэнд автоматаар нээгдэнэ. Бусад route дээр гарын авлагыг гараар нээж болно. Tab focus ба Esc дэмжлэгтэй.
2. Install banner-ийн хаасан төлөв дараагийн event/remount дээр хадгалагдана. Storage хаалттай үед тухайн session дотор санана.
3. Жагсаалтын status/type/district/q шүүлтүүрүүд URL-д хадгалагдаж буцахад сэргээнэ. Зарын линк дарахад scroll-ийг session-д санана; олон хуудас нэмэлтээр ачаалсан урт жагсаалтын яг тэр байрлал сэргээхийг browser-оор шалгаагүй.
4. Алдсан болон олдсон зарын форм эхэндээ нэвтрэхийг шаардана. Нэвтэрсний дараа одоогийн route дээр форм нээгдэнэ. Нэвтрэх имэйл холбоос өөр tab нээх урсгалыг бодитоор шалгаагүй.
5. Тестийн зарын хяналтын read-only SQL бэлэн. Production өгөгдлийг өөрчлөөгүй.
6. Шинэ/засах үрчлүүлэлтийн нас нэгжтэй байна (2 жил, 6 сар). Хуучин тоон утгыг нэгж тодорхойгүй гэж тэмдэглэнэ. Нэгжийг таамгаар хөрвүүлэхгүй.
7. Монгол/англи хэл солиход HTML lang шинэчлэгдэнэ.
8. profile/page холимог гол текстүүдийг монголчилсон.
9. Хуваалцах тайлбар desktop/mobile боломжтой үйлдлүүдтэй нийцсэн.
10. Navbar-ийн одоо байсан hover/focus тайлбарыг хадгалж title болон илүү том дарах талбай нэмсэн. Mobile цэсэнд нэртэй холбоосууд хэвээр.

- notify-on-new-pet: тест эсэхийг баталгаажуулах.
- Lucky Boy давхардлууд: нэр давхцах нь тест гэсэн баталгаа биш.

Баталгаажуулсан ID-уудыг backup хийсний дараа архивлах тусдаа ажил үлдсэн. Зүгээр resolved=true болгож амьтан олдсон мэт худал тэмдэглэхгүй.
Туршилтын заруудыг цаашид staging Supabase/Vercel төсөлд үүсгэх.

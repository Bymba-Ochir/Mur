# Хэрэглэгчийн урсгал

| Урсгал | Дараалал | Шалгах нөхцөл |
|---|---|---|
| Алдсан/олдсон | Жагсаалт → detail → холбоо/харсан мэдээлэл | Guest, эзэмшигч, өөр хэрэглэгч |
| Зар нийтлэх | Нэвтрэх → form → зураг → validation → хадгалах | Failure draft, duplicate submit |
| Үрчлүүлэлт | Жагсаалт → detail → хүсэлт → эзэмшигчийн шийдвэр | Applicant/owner эрх |
| Асрах | Жагсаалт → detail → огноо → хүсэлт → шийдвэр/үнэлгээ | Давхцал, үнэ, зөв төлөв |
| Messages | Conversation → message → read state | Зөвхөн оролцогч |
| My Pets | Амьтан → эрүүл мэнд → reminder | Зөвхөн эзэмшигч |
| Clinics | Filter/map → утас/page → цагийн хүсэлт | Хүсэлт нь эмнэлгээр батлагдсан цаг биш |
| Profile/settings | Profile → edit → preferences/export/delete | Хувийн мэдээлэл, account солих |
| Admin | Dashboard → moderation → audit | Server/database admin эрх |

Form бүр hint, validation, loading, error/retry, disabled төлөвтэй эсэхийг шалга. Modal Esc/X, focus, scroll lock, mobile keyboard-ийг бодит browser дээр туршина. Indigo/Coral/Sky palette-г хадгалж нэг feature-д зориулж бүх загварыг солихгүй.

# МӨР v81

Чатын дэлгэрэнгүй:
- Чат болон хэрэглэгч бүр тусдаа төлөвтэй. Хуучин текст шинэ чатад үлдэхгүй.
- Чатнаас гарсны дараа илгээх хүсэлтийн хариу шинэ чатад нөлөөлөхгүй.
- Илгээх хүсэлт давхар үүсэхгүй.
- Хуучин realtime callback-ийг үл хэрэгсэнэ.
- Алдаатай илгээлтийн текст сэргээх ба retry урсгалыг тестээр шалгасан.

TypeScript, ESLint, 130/130 тест амжилттай.
Build болон live/mobile харагдацыг дахин баталгаажуулаагүй. Өмнөх build оролдлогыг автомат approval review Sentry рүү source map/telemetry илгээж болзошгүй гэж хориглосон тул давтаагүй.
Өмнөх шинэчлэлүүд багтсан. Нэмэлт SQL шаардлагагүй. .env.local файлаа хадгална.

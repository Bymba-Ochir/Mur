# UI/UX Review

Компонент болон хуудсыг UI/UX шалгалт хийх заавар.

## Шалгалтын жагсаалт

### 1. Дизайн систем (МӨР-ийн загвар)
- [ ] **Өнгө**: `--primary`, `--accent`, `--brand` токеныг ашигласан уу?
- [ ] **Фонт**: `--font-display` (гарчиг), `--font-body` (текст), `--font-mono` (badge) тус тусдаа юу?
- [ ] **Зай**: `--sp-1`–`--sp-8` token ашигласан уу? Зөрүү gap/margin/padding байна уу?
- [ ] **Радиус**: `--r-sm`, `--r-md`, `--r-lg`, `--r-xl` тогтмол ашигласан уу?
- [ ] **Сүүдэр**: `--shadow-sm`, `--shadow-md`, `--shadow-lift` ашигласан уу?

### 2. Responsive (мобайл → desktop)
- [ ] **≤480px**: Товчнууд бүтэн өргөнтэй, тэмдэгтийн хэмжээ томссон эсэх
- [ ] **≤640px**: Grid 1 багана болж байгаа эсэх
- [ ] **≤768px**: BottomNav харагдаж байгаа эсэх
- [ ] **≥860px**: Preview карт харагдаж байгаа эсэх (form хуудсууд)
- [ ] **≥1025px**: Навигаци desktop хэлбэртэй эсэх
- [ ] `min-height: var(--touch-target)` товчнуудад байгаа эсэх (44px minimum)

### 3. Accessibility (a11y)
- [ ] Бүх зурган дээр `alt` text байгаа эсэх (empty alt эсвэл descriptive)
- [ ] Form талбарууд `htmlFor`/`id` холбогдсон эсэх
- [ ] Товчнуудад `aria-label` байгаа эсэх (зурагтай товчнууд)
- [ ] Skip link ажиллаж байгаа эсэх (`Tab` дарахад)
- [ ] Focus visible state байгаа эсэх (`:focus-visible`)
- [ ] Keyboard navigation ажиллаж байгаа эсэх (Enter/Space товчнууд)
- [ ] `aria-live="polite"` динамик контентэнд байгаа эсэх (toast, loading)

### 4. Гоо зүй (Aesthetics)
- [ ] **Consistency**: Бүх картууд ижил хэмжээтэй, ижил бүтэцтэй эсэх
- [ ] **Hierarchy**: Гарчиг → дэд гарчиг → текст → muted гэсэн түвшин тодорхой эсэх
- [ ] **Whitespace**: Элементүүд хэт ойр эсвэл хэт хол байгаагүй эсэх
- [ ] **Micro-interactions**: Hover, focus, click бүрд transition байгаа эсэх
- [ ] **Empty state**: Хоосон жагсаалтад зөв мессеж + CTA байгаа эсэх
- [ ] **Loading state**: Skeleton/_spinner ачааллалтын үед харагдаж байгаа эсэх

### 5. Хэрэглэгчийн урсгал (User Flow)
- [ ] Алхам бүрээс буцах боломжтой эсэх
- [ ] Submit-ийн дараа амжилт/алдаа мессеж харагдаж байгаа эсэх
- [ ] Required талбарууд тодорхой тэмдэглэгдсэн эсэх (* эсвэл өнгөөр)
- [ ] Хэт урт текст тасрахгүй байгаа эсэх (`text-overflow`, `line-clamp`)
- [ ] Мобайл дээр товчнууд хэт жижиг биш байгаа эсэх (≥44px)
